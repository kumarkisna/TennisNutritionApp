---
name: Date-of-birth age semantics
description: Product rules for age entry, persistence, and date-specific planning.
---

Age is always derived from an optional date of birth; manual age entry is not supported. When DOB is absent, age must be cleared. Planner calculations use age on the selected planner date, while person/profile displays use age today.

**Why:** The user requested automatic age calculation and chose to clear existing saved ages that have no DOB.

**How to apply:** Preserve these rules in person forms, storage/backup migrations, profile displays, and date-specific planning calculations.
